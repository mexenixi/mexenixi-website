Open source

Sort & Done! is planned as a fully free open-source app. After App Review approval and before manual App Store release, the verified source code, product specifications, technical documentation, and test records will be published on GitHub. Source code will be available under Apache License 2.0, while the Mexinenixi and Narabi names, logos, app icons, screenshots, and store artwork remain outside the source-code license. Bug reports, suggestions, translation help, and code contributions will be welcome, but replies and acceptance cannot be guaranteed for every submission.
